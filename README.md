# Hi, I'm Evan 👋

**Data Engineer** with 4+ years building and maintaining production data pipelines on **Snowflake, Databricks, AWS, and Azure** across **telecommunications and healthcare**.

- 🏗️ I build ETL/ELT pipelines with **Snowflake, dbt, Airflow, PySpark, and Delta Lake**: medallion architecture, incremental processing, and CDC/SCD patterns.
- 📈 My pipelines have processed **~250 GB/day** (telecom) and **~150 GB/day** (healthcare), delivering analytics-ready data to analysts, data scientists, and product and marketing teams.
- ⚡ I've cut production runtimes by **35-40%** through query tuning, incremental processing, and right-sized compute.
- 🎓 **M.S. in Data Science & Analytics**, New England College
- 📜 **AWS Certified Data Engineer – Associate**
- 🔎 Open to Data Engineer roles
- 💬 Always happy to talk pipelines, Snowflake and Spark tuning, or lakehouse design.
